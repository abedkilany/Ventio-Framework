جاهزية Host المستقلة

الحالة: مكتمل (PASS)

على كمبيوتر Windows 11 منفصل، أُجري تثبيت جديد وأُكمل Host Setup عبر Flutter. بعد إعادة التشغيل، أُغلق Flutter وتأكد المالك من بقاء الخدمتين تعملان، ثم أعاد فتح التطبيق. أظهرت الصور Host Overview بحالة READY وHost Settings بجلسة مدير موثقة.

ما تم التحقق منه: إتمام خطوات إعداد Host الست، والخدمتان VentioPostgres وVentio Host Engine بحالة Running وبدء Automatic بهويتي الخدمة المقصودتين، وجاهزية API وPostgreSQL والمخطط وRecovery Authority، واستعادة جلسة المدير بالنطاق الدقيق والصلاحيات الست بعد إعادة التشغيل.

دليل الشبكة (2026-11-01): على جهاز التطوير ذي Host قائم، اكتمل تحديث المثبت دون إعادة تهيئة قاعدة البيانات. خدمتا Host وPostgreSQL تعملان بهويتيهما المقصودتين، والمنفذ 8443 يستمع على 0.0.0.0، وطلب HTTPS محلي إلى /healthz أعاد 200. قاعدة الجدار الناري مفعّلة على البرنامج الصحيح، ومنفذ TCP 8443، وملف تعريف Private، ونطاق LocalSubnet. صور المالك بعد تثبيت النسخة ذات البصمة المطابقة تعرض في Host Settings عنوان LAN ‏https://HOST_PRIVATE_LAN_IP:8443 وبصمة شهادة TLS وتحذير الشهادة الذاتية. من جهاز الاختبار CLIENT_PRIVATE_LAN_IP أعاد طلب HTTPS إلى /healthz الاستجابة 200 ‏(alive)؛ استخدم curl خيار --insecure، لذا لم يتحقق من بصمة الشهادة. هذا الجهاز لديه أيضاً خدمتا Host وPostgreSQL محلياً، ولذلك يصلح لفحص الشبكة لكنه ليس تثبيت Client نظيفاً.

دليل ما بعد إعادة التشغيل: بعد إعادة تشغيل Host، أظهرت Services الخدمتين Ventio Host Engine وVentioPostgres بحالة Running وبدء Automatic بهويتيهما المقصودتين. بقيت Host Settings تعرض مستمع HTTPS وبصمة الشهادة والجلسة الموثقة. ومن جهاز آخر نجح Test-NetConnection من CLIENT_PRIVATE_LAN_IP إلى HOST_PRIVATE_LAN_IP:8443 بنتيجة TcpTestSucceeded: True. هذه الأدلة تغلق متطلبات Host Standalone Readiness؛ إقران Client فعلي والتحقق من الثقة بالشهادة داخل Client يظلان خطوتين منفصلتين. عيب الاسترداد HOST_DATABASE_RECOVERY_ROLE_ROTATION_FAILED مستقل لمسارات الاسترداد والترقية ولا يمنع جاهزية التثبيت الجديد. كان إجمالي القبول وقت توثيق هذا الدليل 20%؛ ارتفع القبول الرسمي لاحقاً إلى 60% بعد قبول Stages 1 و2 و5 و6.

إعادة فحص منفصلة (2026-11-02): على حاسوب التطوير الحالي، وجدت القراءة فقط أن خدمتي VentioHost وVentioPostgres متوقفتان، وأن طلب http://127.0.0.1:8080/healthz رُفض. لم تُشغّل أو تُعدّل أو تُحذف خدمة أو بيانات. هذه الحالة لا تنقض دليل إعادة التشغيل على حاسوب Windows 11 المنفصل، ولا تحدد سبب توقف الخدمات على هذا الحاسوب.
