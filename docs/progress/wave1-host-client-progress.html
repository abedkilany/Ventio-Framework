العمل والتحقق

الأعمال المنجزة

  • أُنجز Task 02: وسيط Named Pipe ثابت العملية، يسمح لمستخدم محلي بصلاحية Administrator فقط، ويرفض اتصال NETWORK؛ ويقيّد الرسائل إلى تهيئة أول مدير أو إقرار استلام بيانات الاعتماد.
  • يُحفظ إيصال العملية في ملف DPAPI محمي، ويرتبط بـSID الخاص بالمُثبّت والطلب نفسه. لا تُكشف بيانات الاعتماد مجدداً بعد الإقرار، وتظل إعادة المحاولة للطلب نفسه ممكنة قبل الإقرار.
  • تُهيأ Recovery Authority من خلال معاملة قاعدة بيانات فارغة، ويُسمح باستعادة انقطاع ما بعد الالتزام فقط عند تطابق إيصال المدير الأول بالكامل. يسجل التدقيق بيانات منقحة دون الرمز السري أو بصمته.
  • أضيفت أداة ventio_identity_bootstrap.exe إلى تعريف بناء payload وفحص manifest والتسجيل والتحقق. لم يُستبدل payload أو المثبت الحالي.
  • في Task 03، لا تعلن الخدمة حالة Running حتى ينجح Host في فحوص قاعدة البيانات وRecovery Authority وربط المستمع؛ ويُتحقق من SHA-256 للملفات التنفيذية الأربعة قبل التسجيل.
  • ينتظر إجراء التسجيل تأكيد Running بعد البدء. اجتازت اختبارات الخدمة وPowerShell المحددة، لكن هذا تحقق برمجي ومخططي فقط.
  • في Task 04 أُضيف معالج Host داخل التطبيق المشترك وربطه بتهيئة المدير الأول عبر broker محلي؛ اجتازت اختبارات Flutter المحددة 7/7 وبناء Windows Release.
  • في Task 05 أُضيفت تهيئة Host والترحيلات وبيانات اعتماد migrator المحمية والنسخ الاحتياطي قبل الترقية والإزالة مع اختيار الاحتفاظ؛ ثُبتت التغييرات في 844ed05.
