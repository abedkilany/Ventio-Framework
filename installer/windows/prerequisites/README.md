# Visual C++ Runtime Build Input

The unified Windows installer embeds the unmodified Microsoft x64 Visual C++ Redistributable package. This executable is intentionally not committed to the repository. The installer builder reads the package from `%LOCALAPPDATA%\VentioFramework\vc-runtime\14.51.36247.0\vc_redist.x64.exe` by default; pass an alternate verified path with `-VCRedistPath`. A copy from the pinned Visual Studio Build Tools installation may be supplied if it matches the package manifest exactly. The package is copied into the compiled Ventio installer, so target Windows computers can install Ventio without internet access.

The accepted build input is pinned in `vc-runtime-prerequisite.json`: Microsoft Visual C++ Redistributable 14.51.36247.0, minimum required runtime 14.50.35719.0, SHA-256 `843068991daaa1f73ad9f6239bce4d0f6a07a51f18c37ea2a867e9beca71295c`. The builder verifies its SHA-256, file version, size, and valid Microsoft Authenticode signature before Inno Setup can embed it. The minimum runtime matches the MSVC 14.50 toolset used for the Windows application. Do not replace it with individual DLL files or modify the Microsoft package.

To obtain the pinned package on a build computer, download `https://aka.ms/vc14/vc_redist.x64.exe` and save it as `%LOCALAPPDATA%\VentioFramework\vc-runtime\14.51.36247.0\vc_redist.x64.exe`, or pass its path with `-VCRedistPath`. The installer output bundles that file; the target PC does not need network access.

Microsoft's Visual Studio 2026 redistribution list permits licensed Visual Studio users to redistribute the unmodified runtime package as part of their program's installation package, subject to the applicable Visual Studio license terms. Distribution of the compiled Ventio installer is conditional on satisfying those terms. See [Visual Studio 2026 redistribution](https://learn.microsoft.com/en-us/visualstudio/releases/2026/redistribution) and [the latest supported Visual C++ Redistributable downloads](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170).
